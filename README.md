# Minha primeira página pessoal

Uma página simples com apresentação e links, feita com HTML e CSS. Não precisa instalar pacotes nem criar uma conta adicional para abrir a página.

## Como abrir

Baixe os arquivos do projeto para o seu computador, mantendo `index.html` e `style.css` na mesma pasta. Clique duas vezes em `index.html` para abrir no navegador.

Se os arquivos já estiverem publicados no GitHub, você poderá baixar a pasta pelo botão **Code → Download ZIP** e extrair o ZIP antes de abrir a página.

## Como personalizar

- Em `index.html`, troque **Seu nome** pelo seu nome e edite os textos de apresentação.
- Os links atuais apontam para o perfil `DeaDinGx` e o repositório `Teste` no GitHub. Você pode trocar os endereços no atributo `href`.
- Em `style.css`, você pode mudar as cores, os tamanhos e os espaços.
- Salve os arquivos e atualize a aba do navegador para ver suas alterações.

## O que cada arquivo faz

- `index.html`: define o conteúdo e a estrutura da página.
- `style.css`: define a aparência da página e adapta o layout para telas menores.
- `README.md`: guarda estas instruções.

## Servidor local opcional

Se você tiver Python 3 instalado, execute na pasta do projeto:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8000` no navegador do seu computador. Para encerrar o servidor, pressione `Ctrl+C` no terminal.
